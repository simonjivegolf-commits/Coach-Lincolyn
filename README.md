# Coach Lincolyn

Responsive website for Coach Lincolyn junior and adult golf coaching, caps and visors.

**Nothing beats consistency.**

## Run locally

Open `index.html` in your browser, keeping the other files and `assets/` folder alongside it.

Alternatively, serve this directory with any static HTTP server. For example, with Python installed:

```sh
python -m http.server 8000
```

Then open http://localhost:8000.

No build step or package installation is required. Fonts and photographs are included locally.

## Pages

- `index.html`: homepage
- `coaching.html`: junior and adult coaching, learning journey and October 2026 package
- `shop.html`: caps and visors, colour and quantity choices, item totals
- `about.html`: coach introduction and philosophy
- `contact.html`: prepared WhatsApp enquiry form

Shared styles are in `style.css`, fonts in `fonts.css`, and interactions in `script.js`.

## Enquiries and ordering

Enquiries open WhatsApp using the supplied contact number. Visitors choose when to send their message. The site does not store enquiries, process payments or complete orders. Product availability, fit, fulfilment, exchange terms and coaching arrangements are confirmed directly.

## Content maintenance

The October 2026 coaching offer is time-specific and should be reviewed or removed when it ends. Confirm the venue, session lengths, programme terms, professional qualifications and product specifications before publishing new claims. Product prices come from the supplied adverts: visors KSh 350 and caps KSh 400.

## Verification

The redesign was checked at phone, tablet and desktop widths. Checks covered local links and assets, mobile navigation, FAQs, product totals, prepared enquiry messages and main text/button contrast combinations.
